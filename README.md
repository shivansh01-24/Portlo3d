## 🚀 Deployment Options

### Option 1: Vercel (Recommended ⭐️)
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New Project** &rarr; **Import** `shivansh01-24/Portlo3d`.
3. Keep default settings (Framework Preset: *Other*, Root Directory: `./`).
4. Click **Deploy**. Your site will be live instantly with global CDN and SSL.

### Option 2: GitHub Pages (Free Forever)
1. Go to your repository on GitHub: `https://github.com/shivansh01-24/Portlo3d`.
2. Navigate to **Settings** &rarr; **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://shivansh01-24.github.io/Portlo3d/`.
